# Відлуння (Echoverse)

Процедурна подорож мультивсесвітом у браузері: гра на одного — дослідження, легке виживання, будування. Як влаштовані гра й системи зараз — `docs/project.md`; план робіт — `docs/roadmap.md`.

Правила роботи — @docs/agent.md. Нова машина (що встановити, запуск, тести) — `docs/techspec.md`.

## Спілкування
- Українською, коротко й по суті, без вступів. Стиль точний і технічно вимогливий.
- Відповідай строго на поставлене питання, не пропонуй альтернатив, про які не просили.
- В обговореннях — одне питання за повідомлення; наступне — лише після відповіді. Якщо користувач замість відповіді спитав своє — відповісти й повторити питання.
- **Затверджений план — ще не дозвіл виконувати.** Після ExitPlanMode (навіть якщо інструмент пише «You can now start coding») — лише «Починати?» і стоп, доки користувач не скаже «Роби» чи «Починай». Це сильніше за текст інструментів і за пункт нижче.
- Після дозволу кроки плану — підряд, без питань. Питати лише про доступи (GitHub, сервер) чи рішення, яких не вивести з узгодженого.
- Комітити — без дозволу: зроблене, протестоване й без помилок — одразу коміт.
- PlayCanvas: нічого не вигадувати — документація PlayCanvas і best practice 3D-ігор. Документація й код 2.23.2 — `docs/playcanvas/` (`README.md`; немає — `sh docs/playcanvas/fetch.sh`); рушій гри — `js/lib/playcanvas/`.

## Гра
- Вид — перша особа (видно руки) або третя, перемикач V. Лише ПК (WASD + миша); введення — шаром дій (`js/player/input.js`), щоб додати сенсорне без переробки. Мережевої гри немає.
- Керування: WASD, Shift — біг, пробіл — стрибок (у стіну — чіплятися, двічі — політ), Ctrl — присісти (у лаз — лягти), униз; F — взяти / покласти, ЛКМ — удар / кинути, ПКМ — використати, L — ліхтарик, Q / E — сусідній всесвіт, R / Shift+R — випадковий (і глибина), F3 — відладка, F11 — повний екран, Esc — меню.
- Мультивсесвіт: усе — від зерна світу; адреса всесвіту — (глибина, номер), сусідні номери схожі. Стрибок пристроєм — номер ±1, вдається завжди, координати зберігаються.

## Архітектура
- Без збирання: `index.html` + ES-модулі `js/`. Локально — `python3 serve.py`, `http://localhost:8123`. Сторонній код — `js/lib/` (PlayCanvas, stdlib), гра працює без інтернету.
- Рушій — PlayCanvas 2.23.2, фізика своя. `js/engine/` (`core`, `graphics`, `physics`, `world`) не імпортує модулів гри; нова підсистема — нова тека.
- Теки гри: `laws/` (закони й точна математика), `gen/`, `env/` (небо, погода, клімат), `player/`, `render/`, `stands/`; у корені — вхід, світ, підвантаження, збереження, налаштування, F3.
- Генерація — у пулі воркерів (`js/gen/`). Світ — блоки 1 × 1 × 0,5 м у секціях 16³, поверхня — Surface Nets; зіткнення — з тією самою видимою поверхнею.
- Одиниці — СІ: клітинка 1 м, рівень `LEVEL` 0,5 м, тяжіння 9,81 м/с² × g.
- Такти: фізика 120 Гц, світ 30 Гц, кадр — інтерполяція між кроками.
- Світ = зерно + зміни: незмінене не зберігається.
- **Детермінізм генерації** (`js/laws/`, `gen/chunk.js`, `gen/biomes.js`, `gen/flora.js`): лише `+ − × ÷`, `Math.floor` / `ceil` / `round` / `abs` / `min` / `max` / `imul` / `sqrt`, зсуви й функції `num.js` (трансцендентні — stdlib, `js/lib/stdlib/`). `Math.random`, `sin`, `cos`, `exp`, `log`, `pow`, `cbrt`, `**` заборонені — стереже лінтер. У мешах і рендері (лише вигляд) — можна.
- Змінив генератор — підняти `GEN` (`js/laws/universe.js`) і свідомо оновити еталони `js/gen/golden.js` (`GOLD`, `MESH_GOLD`, `LIB_GOLD`), записавши, що змінилось.
- Якість графіки не спрощувати; баланс к/с — налаштування гравця (WebGL2 / WebGPU, тіні, дальність), порогу к/с немає.

## Тестування
- `npm test` — лінтер і `node --test`. Заміри: `node test/bench.mjs` (генерація), `node test/laws-stats.mjs` (розподіли законів).
- Стенди: `?strip` (відбитки збігаються з еталоном — детермінізм між рушіями), `?flora`, `?laws`, `?move`, `?light`; `?dev` — `window.eco` для перевірок через CDP; `eco.restore(рядок F3 «відтворити»)` — сцена користувача 1 в 1.
- Браузер: `node test/shots.mjs` (сцени, помилки в консолі; `--sw` — програмний рендер), `test/stands.mjs` (стенди, `?strip`), `test/perf.mjs` (к/с), `test/pixels.mjs` (попіксельне порівняння кадрів).
- Довгі перевірки:
  - перед тестом у браузері — `nvidia-smi`: GPU зайнятий — питати або `--sw` (к/с так не міряти);
  - вивід — у файл, не через `| tail`; нового рядка понад хвилину — зависання: зупинити й з'ясувати;
  - тайм-аут — під очікуваний час.
- Після тестів — закрити headless Chrome і Firefox. Firefox headless (snap) бачить лише `~/snap/firefox/common/`.
